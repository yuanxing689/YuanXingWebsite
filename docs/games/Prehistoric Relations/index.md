![RP1](./images/PR1.webp)

欢迎来到海滨观景镇（Oceanview），新来的同学！我们将跟随Sam——
一只刚刚转学来到化石大学（Fossile University）的恐鳄，开启一段校园生活。
去结识那些属于史前时代的同窗吧：有恐龙、冰河巨兽，
甚至还有古生代的奇行种。在这个世界里，Sam将邂逅并应对镇上那些最具个性的家伙们，
并与这些奇特的角色发展出不同的关系 <3

本作主打喜剧剧情，而非传统的恋爱故事，每一条角色路线都将探索不同类型的情感羁绊。

内容警告：​ 本视觉小说为全年龄向（无裸露内容），但包含成人幽默与性暗示主题。建议16岁以上受众游玩。
