## 项目简介

Reyald，一只悲伤的狼，一只孤独的狼，一只拥有着破烂酒吧的狼。每晚他看着指针滴答时辰，那里关着他最好的朋友Sam。
他总说自己是画家，可酒馆只摆一幅画——Felicity，画布是偷来的遗物，颜料混着他血与梦的残渣。他忘了何时画完它，只记得笔触是“蛆虫爬过伤疤的痒”，而画中的眼睛，是唯一能让幻觉闭嘴的开关：
精液是苦的，鲜血是甜的，如今翻痛的伤疤，是往日欢愉的纪念。这些他都会告诉Sam。
只是Sam没有来。但，Sam又是谁?
“我最好的朋友是Amberock。”
