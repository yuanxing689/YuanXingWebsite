仅限成人：内容包含血腥、身体恐怖、暴力、侮辱性言论及英国角色​

他们相识于网络，已多年，但Carter与Hartland的第一次现实会面，却以撕心裂肺的灾难告终。

如今，Hartland穿越半个国家，只为与他所爱的男人一起度过20世纪最后的时光。

然而他所爱之人却发生了惊人的转变。他变得自信、开朗、风情万种——

而且突然间，毫无预兆地，​尺寸惊人。

凭借独特诡异的美术风格、魅力十足的角色以及待解的奇妙谜团，愿您能与大鸡巴先生共度一段难忘时光。
